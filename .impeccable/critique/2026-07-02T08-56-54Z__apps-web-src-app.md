# Anti-Patterns Verdict

**Does this look AI-generated? The first fold of the homepage: yes, immediately. The rest: mostly no.** The hero sequence — animated gradient-clipped headline → tracked eyebrow → 4-stat metric band → numbered 4-card glass grid — is the canonical AI-template opening, and every element of it is banned verbatim by PRODUCT.md's own anti-references. The counterweight is real: the packages page (genuine flyers, transparent RM pricing) and the quote page (white A4 paper on the dark stage) could not have been generated by template. With the portfolio empty in production, the slop reading currently wins on first impression.

# Overall Impression

The bones are unusually good for a solo-built platform: a real three-world design system (dark ballroom / light backstage / white paper), a genuinely excellent money moment, and a disciplined admin. But the platform currently leads with its weakest material — a template-shaped first fold and blank portfolio boxes — while its strongest assets (real flyers, transparent pricing, the A4 quote ceremony) sit one or two clicks deep. The single biggest opportunity: make the evidence visible (portfolio + real photos) and make the funnel speak the customer's language end-to-end.

# What's Working

1. **The White Paper money moment** (q/[token] + branded-document.tsx). The customer sees the actual formal document — letterhead, Roxborough serif title, line items, SST, T&C — lifted off the dark stage, with accept/pay/upload-proof on the same page, and designed expired/changes-requested states. This executes "trust at money moments" better than most real invoicing SaaS.
2. **Two-register discipline in the admin.** Flat, bordered, dense, consistent (navy sidebar, tonal badges, uniform row actions) — passes the product-register "earned familiarity" test, never leaks the ballroom aesthetic, and ships a working EN/ZH staff UI.
3. **The enquiry form's IA** (enquiry-form.tsx). Four steps × ≤4 fields, free navigation, inspiration upload, language capture — the right shape for mobile lead capture in this market.

# Priority Issues

1. **[P0] Evidence surfaces are empty in production, and the empty state is decorative.** Home "Selected work" and the entire /portfolio render blank gradient boxes ([locale]/page.tsx:135–153, portfolio/page.tsx:36–45); browser pass confirmed zero images live. For an event decorator, portfolio IS the product; "View our work" leads to nothing, silently. Design Principle #1 inverted. **Fix:** (a) ops: upload real portfolio images via the existing admin page; (b) design: replace placeholder divs with a real empty state — hide the section or point to Instagram — never blank rectangles as content. **Suggested command:** /impeccable onboard portfolio + showcase empty states.
2. **[P1] The money moment and half the funnel ignore the customer's language.** /q/[token] is hardcoded English end-to-end; packages page furniture, stats band, and all server-action error strings are EN-only — yet the platform collects `preferredLanguage` at enquiry and never uses it. On /zh the code-switching reads as "not really for us." **Fix:** extend dictionaries (packages/stats/quote/errors namespaces); resolve quote-page locale from `lead.preferredLanguage`; return error keys from actions, translate at render. **Suggested command:** /impeccable harden public funnel i18n.
3. **[P1] The first fold is the banned AI template and it breaks tenant theming.** Animated gradient headline (globals.css:49–56), hardcoded universal stats band, numbered glass-card grid — all PRODUCT.md anti-references; the gradient/sky-300/blue-glow hardcodes mean a rose-gold tenant still gets blue-violet. Detector agrees (gradient-text + color-drift findings). **Fix:** solid moonlight headline (or static var(--brand) tint); tenant-configured real stats or delete the band; remove 01–04 numbering, one real photo per service card; route eyebrow/glow colors through var(--brand). **Suggested command:** /impeccable shape homepage first fold.
4. **[P1] Zero-confirmation destructive actions across the admin.** One-click "Lost" adjacent to "+ Quote" (leads/page.tsx:180–184), Delete package, delete portfolio/petty-cash/quotation images, and "Resend (new code)" silently invalidating the customer's existing code (quotations/[id]/page.tsx:102–106). Staff use this daily. **Fix:** confirm step or undo-toast on every destructive form; rename Resend to "Resend with new code" + confirm. **Suggested command:** /impeccable harden admin destructive actions.
5. **[P2] Nav has no scrim; packages→enquiry loses context.** (a) Fixed nav is backdrop-blur only (site-nav.tsx:32) — scrolled light content smears into an illegible band (observed live on /en/packages); add bg-[#060c1c]/75 + hairline. (b) "Enquire now" from a package carries nothing — the customer must remember and retype "Package D" on the platform's most important conversion hop; pass ?package=code and echo it in the form. **Suggested command:** /impeccable polish site nav + enquiry handoff.

# Minor Observations

- Services content rendered twice (home + /services), identical copy, no imagery either time; /about is two sentences on an empty viewport — thin pages on an imagery-led brief.
- Off-palette tokens: ink #0b0b10 on /services ≠ evening-navy; violet #a78bfa not in DESIGN.md.
- Alt text is filenames (alt={img.filename ?? "showcase"}) — meaningless to screen readers.
- Duplicate price signal on package cards (baked into flyer + text header) — will contradict when DB prices change.
- Quote status chip prints raw lowercase enum (sent) to customers.
- Footer lacks company registration/address/phone — trust signals absent for a business collecting deposits.
- Admin dates via toISOString().slice(0,10) — UTC-naive for MYT, and inconsistent with document dd/mm/yyyy.
- Pagination renders every page number 1..N — breaks visually past ~15 pages.
- Enquiry date input has no min — past event dates accepted.
- The two radial-glow rgba blues are hand-copied across 3 files — tokenize.
- BO offers EN/ZH only (no BM) — worth a deliberate decision note.

# Questions to Consider
